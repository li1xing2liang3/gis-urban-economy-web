# 交互功能说明

本文档按**全局框架**、**主平台七个功能页面**与**编队调度子应用**说明当前前端（`web`）中**已实现**的交互：控件位置、操作方式、界面反馈，以及哪些是**演示占位**（待接后端或地图服务）。

**产品需求与 URL 状态规则**以 **[PRD-城市经济空间平台.md](./PRD-城市经济空间平台.md)** 为准；本文侧重**操作级**说明。

默认入口：**http://localhost:5173/** → 重定向至 **`/overview`**（空间总览）。

---

## 一、全局框架（所有页面共用）

| 区域 | 交互 | 行为说明 |
|------|------|----------|
| **顶栏** | 无点击交互 | 左侧展示品牌文案「AI+GIS」「城市经济空间展示平台」「融合武汉智眼」；中间为**当前路由页面标题**（随导航变化）；右侧为环境标签「演示」、**实时时钟**（每秒刷新）、「用户」占位（无登录逻辑）。 |
| **全局上下文条**（`GlobalContextBar`） | 选择时间模式/单刻或区间/对比、区域模式（全市/行政区/点选/框选）、**数据源** | 与 `stores/gisState` 的 `gis` 对象绑定；通过 `useGisRouterSync` 将筛选写入**地址栏 query**（见 PRD 中 `GIS_QUERY_KEYS`），便于带状态分享；侧栏切换路由后约 100ms 内会**补全** query。 |
| **分析任务条**（有任务时显示） | 只读 + 「保存结果」 | 各分析页在运行/完成时向 `gis.tasks` 推记录；成功任务可点「保存结果」标记为**已保存**（仅前端状态，持久化到会话级逻辑可后续接接口）。 |
| **左侧导航** | 点击七个 `RouterLink` | 在七个路由间切换，当前项高亮。路由与路径见下表。 |
| **侧栏收起** | 点击 `«` / `»` 按钮 | 收起时仅保留图标，展开时显示菜单文字。 |
| **主内容区** | — | 渲染当前页面对应的 `router-view`。 |
| **底栏** | 无交互 | 显示「全局时间 / 数据版本」组合文案（与 `gis` 中 **数据源** 与 **时间单刻** 同步，非仅静态占位）。 |

### 二维地图页共性（除三维页外）

凡使用 **`useLeafletMap`** 的页面均包含：

| 交互 | 行为说明 |
|------|----------|
| **地图拖拽 / 滚轮缩放** | Leaflet 默认交互；底图为 OpenStreetMap 栅格。 |
| **湖北省界** | 启动后自动加载 `public/geo/hubei/hubei.*`，叠加省界并**缩放到全省**（失败则退回武汉中心）。 |
| **缩放控件** | 地图左上角 `+` / `-`。 |

## 二、通用组件：图层树（`LayerTreePanel`）

**使用页面：** 空间总览（`/overview`）。

| 交互 | 行为说明 |
|------|----------|
| **图层名称旁复选框** | 切换该图层的「可见」状态；右侧 KPI「图层组合」显示**当前勾选可见数量**。 |
| **透明度滑条** | 仅当该图层**勾选可见**且配置了 `opacity` 时出现；拖动范围 0～1，步长约 0.05。 |
| **行内「智眼/无人机/…」** | 展示该条目的数据来源标签（与 `config/layerCatalog` 中定义一致）。 |
| **「ℹ」** | 打开**图层信息**弹层：来源、指标说明、分级规则、单位（演示级文案）。 |

**与总览页联动的图层：**

- 当前仅 **「经济活力分布（模型）」** 勾选时，会在地图武汉中心附近绘制**橙色演示圆**，其填充透明度受该图层滑条影响。
- 其余图层项（DEM、建筑、道路、POI 等）为**界面占位**：勾选/滑条会更新 UI 与计数，**不会在地图上加载真实图层**（待接服务后扩展）。

## 三、页面 1：城市经济空间总览（`/overview`）

| 交互 | 位置 | 行为说明 |
|------|------|----------|
| **KPI 条** | 顶栏下 | 活力/图层数为**与 `gis` 和图层树**联动的演示指标；**操作**为「选择 / 分析 / 对比」三档按钮（分析/对比主要影响与低空参与相关的演示系数）。 |
| **图层保存 / 截图 / 报告** | KPI 条右侧 | **图层保存**：`localStorage` 保留方案 + `alert` 成功；**截图**：`html2canvas` 导出 `overview-map.png`；**报告**：下载 Markdown 片段（时间、数据源、区域、KPI 等）。 |
| **区域与地图** | 与全局条联动 | 在**全局条**将区域设为**点选**时，在总览图点击可落点并圈 1 km；设为**框选**时在图上按住拖拽出矩形，写入 `gis.region.box`；**行政区/全市**不依赖本页绘制。 |
| **图层树** | 右侧 | 同「二」；底部可显示 **区域统计卡片**（非全市时）及操作提示。 |
| **地图** | 中央 | 省界 + OSM + 活力层演示圆 + 点/框/行政区对应的示意几何。 |

## 四、页面 2：三维城市与经济空间（`/scene3d`）

| 交互 | 位置 | 行为说明 |
|------|------|----------|
| **Cesium 视图** | 全区域 | 鼠标拖拽旋转/平移、滚轮缩放；**Home** 恢复默认视角；**场景模式**在 2D/3D/CV 间切换；**全屏**进入全屏。 |
| **影像底图** | 场景内 | OSM 影像；地形为**椭球**（非真实 DEM）。 |
| **三维图层复选框** | 左上浮动面板 | **建筑白模（演示柱体）**：控制若干演示方柱实体显示/隐藏。**经济指标着色**：开时柱体为蓝/橙配色。地形/无人机项仍为**占位**逻辑。 |

| **建筑左键** | 场景内 | 拾取演示方柱时，在右下 HUD 显示**活力指数**、**商业类型**（与当前 `gis.dataSource` 有简单演示差分）。 |
| **去低空** | 面板内链接 | `RouterLink` 到 `/lowaltitude`，`query` 带 `r=p:30.59…` 等，便于**带位置**联查。 |

## 五、页面 3：经济活力与商业分析（`/vitality`）

| 交互 | 位置 | 行为说明 |
|------|------|----------|
| **数据源、日期** | 左侧 | 与全局 `gis.dataSource`、**日期** 绑定（`type="date"`，与顶栏同一份 `gis`）。 |
| **四个权重滑条** | 左侧面板 | 原始 0～1 浮点；**展示**行显示 **normalizeWeights 归一化**后的占比。 |
| **纳入无人机** | 复选框 | 与 `gis.uavInVitalityModel` 及低空页**参与模型**开关联动。 |
| **实时成图** | 地图 | 在**不改「运行分析」**的情况下，**拖权重**也会重绘**蓝色演示圆**组，体现参数驱动。 |
| **运行分析 / 重算** | 按钮 | 入队 `pushTask`（任务条可「保存结果」），完成后 `setVitalityResult`；地图圆与**片区排名**随**时间因子+权重**变化。 |
| **分解与解释** | 右侧面板 | 因子贡献条 + 主因/次因；左侧有简短**指标来源与拆解**文案。 |
| **地图** | 中央 | 省界 + OSM + 与权重联动的成图。 |

## 十一、跨页链接与 URL 状态

- **侧栏导航**在**无 query** 时切换：内存中的 `gis` 保留；`GlobalContextBar` 的 `useGisRouterSync` 会在**短时间**后 `replace` 补全 query（`GIS_QUERY_KEYS` 定义的全局键），避免长期裸路径。  
- 显式带 `query` 的 `RouterLink` 见下表与 PRD；**合并规则**为：保留非 gis 键 + 以当前 `gis` 覆写 gis 键，从而可**清除**如旧 `did`。

| 起点 | 控件 | 目标（示例） |
|------|------|--------------|
| 三维 | 去低空 | `/lowaltitude?r=p:…` |
| 低空 | 三维/总览/活力 | `/scene3d`、`/overview`、`/vitality`；三维常带 `r` |
| 低空 | 编队调度 | `/fleet-dispatch` |
| 编队 | 返回 GIS 平台 | `/overview` |
| 首页 | 协同调度应用 | `/fleet-dispatch` |

## 十二、演示与生产差异（阅读须知）

当前版本以**可点击、可看见反馈**的演示为主：大量按钮与选项已预留交互，但**数据与算法未接后端**。后续接 API 时，建议保持同一套控件语义，在本文档同位置补充「接口名 / 字段 / 错误态」即可。
