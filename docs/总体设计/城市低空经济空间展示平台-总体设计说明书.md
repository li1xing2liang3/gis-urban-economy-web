## 1. 系统概况

### 1.1 系统背景

数字城市与智慧城市建设推动下，商业活动、人口流动与产业分布高度空间化。低空经济（无人机航测、倾斜摄影、近地感知）为城市经济分析提供了高分辨率、可复测的数据来源。地理信息系统（GIS）与 Web 可视化技术可将多源数据叠置在统一时空框架下，支撑规划、招商与公共政策讨论。

**与本项目的关系：** 本仓库实现为 **WebGIS 演示应用群**（非政务生产系统）：**主 GIS 平台** + **多无人机协同调度子应用**，以 **「智眼型」城市感知框架** 为**指标体系参考**，数据以 **开放底图、省界矢量、自研模拟与可替换专题层** 为主。对外表述需区分「体系参考」与「真实数据来源」，详见 `docs/数据与智眼说明.md`。

### 1.2 系统目标

| 目标维度 | 说明 |
|----------|------|
| 一屏浏览 | 在同一套时间、区域、数据源筛选下浏览全省/都市经济区专题页面 |
| 二三维一体 | 二维 Leaflet 专题页 + Cesium 三维场景页；底图与行政区上下文一致 |
| 可解释展示 | 图层树展示数据来源标签（演示/模型/POI 等）、指标与单位（演示级） |
| 流程闭环演示 | 参数调节 → 触发分析任务条 → 截图 / Markdown 报告 / 本地书签；编队仿真 → 任务队列 / 活力回写 |
| 可演进架构 | 全局状态 `gis` 与 URL 查询同步（`gisToQuery()`），便于后续接入 REST/OGC 服务 |
| 应用群扩展 | 编队调度独立路由与布局，共用 `gisDataService` 与武汉 Mock 数据集 |

### 1.3 系统建设任务（与仓库目录对应）

| 建设任务 | 仓库实现位置 |
|----------|----------------|
| Web 前端主体 | `web/`（Vue 3 + Vite） |
| 省界与静态地理资源 | `data/geospatial/...` → 同步至 `web/public/geo/hubei/` |
| 编队调度子应用 | `web/src/views/fleet/`、`FleetDispatchLayout.vue` |
| 湖北省各市州模拟专题数据（演示） | `web/scripts/generate-hubei-mock-datasets.mjs` 生成 `web/public/data/mock/hubei/*.geojson|json` |
| 武汉编队仿真扩展 | `web/scripts/generate-wuhan-simulation-extension.mjs` → `uav-fleet-*.json` |
| 产品说明与交互细则 | `docs/PRD-城市经济空间平台.md`、`docs/交互功能说明.md` |

**不在本期交付范围内（可在文档「展望」中保留）：** PostgreSQL/PostGIS 服务端库、GeoServer 实例化部署、Python 模型微服务集群——现有 Word 初稿中的该类表述视为 **目标架构**，与本仓库 **当前代码** 不一致处，以本文「实现范围」为准。

## 2. 需求规定

### 2.1 现状分析

#### 2.1.1 数据现状（实际）

- **已接入浏览器侧：** 湖北省界 Shapefile（经 `shpjs` 解析为 GeoJSON）、OSM XYZ 底图。  
- **模拟演示：** `city-units.geojson`、`poi-sample.geojson`、`timeseries-*.json`（均由脚本生成，POI 已与省界求交约束）。  
- **智眼/低空生产数据：** 未接入；界面保留参数与文案占位，便于后续替换。

#### 2.1.2 功能现状（实际）

- **已实现：** 七大全专题视图 + **编队调度三页**（路由见 §5）、全局上下文条、分析任务条、图层树（总览）、书签与导出（html2canvas）。  
- **演示逻辑：** 商圈、活力等「运行」多为前端异步任务与几何绘制，非服务端持久化计算。

#### 2.1.3 与目标架构的差异说明

初稿 Word 中描述的「FastAPI + PostgreSQL + GeoServer + 微服务」属于 **可扩展目标**。当前仓库验证路径为 **纯静态前端 + 本地/静态 JSON**，用于快速验证交互与汇报演示。

#### 2.1.4 运行环境与网络

- **客户端：** 现代 Chromium 内核浏览器（Edge / Chrome）。  
- **开发：** Node.js LTS，`npm run dev`（Vite 默认 `http://localhost:5173/`）。  
- **部署：** 可将 `web/dist` 静态发布至任意 HTTPS 静态托管；底图依赖外网 OSM（可按需替换为国内合规瓦片）。

### 2.2 数据需求

| 类别 | 内容 | 本期形态 |
|------|------|----------|
| 基础地理 | 省界、（可选）市界 | 省界 shp；市州面为演示圆或多边形 |
| 底图 | 路网、水系、注记 | OSM |
| 专题 | POI、活力、人口、动态、低空 | 静态 GeoJSON/JSON + 前端绘制 |
| 元数据 | 来源、坐标系、时间 | GeoJSON `meta` + PRD 文档 |

### 2.3 功能需求概要

与 PRD 矩阵一致：总览、三维场景、经济活力、商圈、人口、经济动态、低空增强、**多机协同调度**；并支持全局筛选同步、任务状态、导出物。

### 2.4 非功能性需求

| 类型 | 要求 |
|------|------|
| 性能 | 矢量适中时在桌面浏览器流畅交互；大图斑/WMTS 建议后续服务端切片 |
| 兼容 | 现代浏览器；Cesium 三维页优先桌面 GPU |
| 可维护 | TypeScript + 模块化视图；路由懒加载 |
| 安全 | 纯前端演示：**无登录鉴权**；正式部署需另行设计 |

## 3. 总体设计

### 3.1 设计依据与原则

- 遵循院系模板与国家标准文档惯例；技术选型遵循先进性与可落地性平衡。  
- **实现原则：** 前后端分离接口契约预留；当前以后端空实现 + 静态文件代替。

### 3.2 总体技术路线（实际）

```
Vue 3（Composition API）
  └── Vite 5（构建）
        └── vue-router 4（路由）
              ├── Leaflet 1.9 + shpjs（二维地图与省界加载）
              ├── Cesium + vite-plugin-cesium（三维）
              └── html2canvas（截图导出）
```

全局状态与路由查询同步：`web/src/stores/gisState.ts`；布局与顶栏：`MainLayout.vue`、`GlobalContextBar.vue`、`AnalysisTaskStrip.vue`。

### 3.3 系统逻辑分层（实现视图）

| 层次 | 职责 | 典型路径 |
|------|------|----------|
| 表现层 | 各专题页面、图层树、图表 | `web/src/views/*.vue` |
| 状态层 | GIS 全局状态、URL 同步、任务队列 | `web/src/stores/gisState.ts` |
| 地图能力层 | Leaflet 初始化、省界加载 | `web/src/composables/useLeafletMap.ts` |
| 配置与类型 | 图层目录、类型定义 | `web/src/config/layerCatalog.ts`、`web/src/types/*.ts` |
| 静态资源层 | 地理文件、模拟数据 | `web/public/geo/`、`web/public/data/mock/hubei/` |

### 3.4 部署架构（本期）

单静态站点：`npm run build` → `web/dist` → Nginx / GitHub Pages / 校内镜像均可。

### 3.5 演进架构（规划对齐 Word 初稿）

后续可增加：**REST API**、**PostGIS**、**OGC 服务（WMS/WMTS/WFS）**、**模型服务（商圈聚类、活力回归等）**；前端已通过 `gisToQuery()` 与图层 ID 预留接入点。

## 4. 数据库设计

### 4.1 本期说明

**当前工程无独立服务端数据库。** 持久化仅限：

- **浏览器本地：** 书签与部分导出逻辑依赖浏览器存储（见 `exportAndBookmark.ts`）。  
- **文件系统：** 静态 GeoJSON/JSON 作为「逻辑数据库」。

### 4.2 逻辑数据模型（演示）

| 逻辑实体 | 载体 | 说明 |
|----------|------|------|
| 行政边界 | `湖北省.*` → `hubei.*` | 县级及以上示意边界 |
| 市州单元 | `city-units.geojson` | 演示属性：活力、人口密度示意等 |
| POI | `poi-sample.geojson` | 业态类别、重要性；坐标约束于省界内 |
| 时序指标 | `timeseries-province.json` 等 | 全省及各市州月度合成指数（演示） |
| 编队调度 | `uav-fleet-dispatch-plan.json` 等 | 方案、遥测、机队、冲突（演示） |

### 4.3 未来物理库（规划）

可按 Word 初稿设计 PostGIS 要素类与栅格表；字段可与上述 GeoJSON 属性对齐，减少迁移成本。

## 5. 系统功能设计

### 5.1 系统划分（路由）

| 路由 path | 页面组件 | 主题 |
|-----------|-----------|------|
| `/overview` | `OverviewView.vue` | 城市经济空间总览 |
| `/scene3d` | `Scene3DView.vue` | 三维城市与经济空间 |
| `/vitality` | `VitalityView.vue` | 经济活力与商业分析 |
| `/districts` | `BusinessDistrictView.vue` | 商圈识别与结构地图 |
| `/population` | `PopulationView.vue` | 人口密度与消费潜力 |
| `/dynamics` | `DynamicsView.vue` | 经济动态与时序分析 |
| `/lowaltitude` | `LowAltitudeView.vue` | 低空数据增强中心 |
| `/fleet-dispatch` | `FleetAppHomeView.vue` | 多机协同调度 · 应用首页 |
| `/fleet-dispatch/workspace` | `FleetDispatchWorkspaceView.vue` | 调度工作台 |
| `/fleet-dispatch/scenarios` | `FleetScenariosView.vue` | 协同方案库 |

**说明：** `/fleet-dispatch/*` 使用 `FleetDispatchLayout`，不继承 `MainLayout`；`/uav-fleet` 重定向至工作台。

### 5.2～5.7 模块说明（摘要）

- **三维模块：** Cesium 场景、预设视角、与低空页跳转联动（详见 `Scene3DView.vue`）。  
- **经济活力：** 权重滑条、`setVitalityResult`、湖北市州模拟面分级设色（读取 `city-units.geojson`）。  
- **商圈：** POI 业态筛选、演示聚类与卡片对比、`districts` 写入全局状态。  
- **人口：** 人口/消费图层勾选项与地图分级设色、`timeseries-province.json` 驱动多序列柱状趋势。  
- **动态：** 时间槽、播放、对比条与合成曲线。  
- **低空：** 参与活力模型开关、与 `uavInVitalityModel` 同步。  
- **通用：** 截图/报告/书签、全局任务条、KPI 与 `regionKpis` 等（见 `exportAndBookmark.ts`、`RegionStatsCard.vue`）。

更细控件级行为见 `docs/交互功能说明.md`。

## 6. 系统接口设计

### 6.1 外部接口（当前）

| 类型 | 说明 |
|------|------|
| 底图 | `https://{s}.tile.openstreetmap.org/...`（可配置替换） |
| 省界 | 相对路径 `public/geo/hubei/hubei`（`shpjs` 拉取） |
| 模拟数据 | `public/data/mock/hubei/*`（`fetch`） |

### 6.2 内部接口（逻辑）

- **状态 ↔ URL：** `gisToQuery()`、`useGisRouterSync()`，键集合 `GIS_QUERY_KEYS`。  
- **未来后端：** 建议统一 `GET /api/v1/...` + JSON（GeoJSON FeatureCollection / 时序表）。  
- **编队调度（已实现 Mock）：** `GET /api/v1/wuhan/uav/fleet-dispatch-plans|fleet-telemetry|fleet-registry|fleet-conflicts?ds=v2026Q1`，由 `gisDataService.getFleet*` 消费。

## 7. 界面设计

- **主布局：** 顶栏 + 全局上下文条 + 内容区 + 底栏/任务条（`MainLayout.vue`）。  
- **编队子应用布局：** 独立顶栏/底栏（`FleetDispatchLayout.vue`），三页路由，可返回主平台。  
- **B/S 响应式：** 以桌面宽屏为主；侧栏宽度固定约 240～280px。  
- **专题图例：** 总览 POI 业态图例、活力页图例条、人口页三序列图例等。
