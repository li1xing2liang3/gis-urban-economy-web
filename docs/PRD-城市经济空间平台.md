# PRD：城市经济空间 WebGIS 展示平台

**版本：** 0.3（与仓库 `web/` 前端实现同步，2026-04-23 修订）  
**产品形态：** 单页应用（Vue 3 + Vite + Leaflet + Cesium）演示环境；**不绑定政务「武汉智眼」生产数据**，以**体系参考 + 开放数据/模拟数据** 支撑展示与模型流程。  
**权威代码：** `E:/GIS project/web/src/`

> **数据现实（课题必读）**  
> 武汉智眼类数据**不视为本项目的可公开获取数据源**；界面中的「智眼系」指**指标体系/版本标签的类比**，**非**已接入官方库或视频流。详见 [数据与智眼说明.md](./数据与智眼说明.md)。  
> **标准表述（论文/申报可用）：**  
> 本研究以**武汉智眼所代表的城市感知数据体系为框架参考**，采用**互联网开放数据与自构造模拟数据**复现城市感知数据结构，在 WebGIS 中实现经济空间分析流程。

---

## 1. 产品目标

| 目标 | 说明 |
|------|------|
| **一图概览** | 同一套**时间、区域、数据源**筛选在全站自动同步。 |
| **可解释** | 图层、模型结果能说明**来源、指标、单位、分级**；分析结果有简要原因文案（演示级）。 |
| **可操作** | 各页提供「选择 / 分析 / 对比」路径；长任务有状态；可导出截图、简易报告、本地方案书签。 |
| **可生长** | 通过 `gis` 状态与 `gisToQuery()` 将筛选写入 URL，便于带状态分享与接后端。 |

---

## 2. 用户与使用场景

- **规划/分析人员**：在总览与专题页看活力、商圈、人口、时序；调整参数后「运行」或实时预览（演示逻辑）。  
- **汇报展示**：用截图、Markdown 报告、图层书签快速固化视图。  
- **跨页面联查**：从商圈页跳转人口时携带当前 URL 中的全局查询参数。  

**非目标（本 PRD 版本）：** 账号与权限、在线协同编辑、服务端出 PDF、全量智眼/无人机生产管线。

---

## 3. 核心概念与全局状态

实现位置：`web/src/stores/gisState.ts`（`export const gis`）。

| 状态项 | 含义 | URL 键（`GIS_QUERY_KEYS`） |
|--------|------|-----------------------------|
| **时间单刻** | `YYYY-MM-DD` | `t` |
| **时间模式** | single / range / play / compareAB | `tm` |
| **时间区间** | 起止日 | `t0`, `t1` |
| **A/B 对比日** | 与动态分析、导航栏强相关 | `ta`, `tb` |
| **区域** | 全市/行政区/点/框的编码 | `r`（`all` \| `a:区名` \| `p:lat,lng` \| `b:south,west,north,east`） |
| **数据源** | 项目内**版本/管线标签**（如模拟「智眼型」时间切片，**非**政务真库 ID） | `ds` |
| **经济动态** | 是否 A/B 对比 | `cmp` = `0` / `1` |
| **人口 A/B 标签** | 两区名称（演示） | `popA`, `popB` |
| **商圈选择** | 当前选中 ID | `did`（**合并到 URL 时会覆盖路由内旧 gis 键，避免残留**） |
| **无人机参与** | 是否进入活力等模型 | `pops` = `0` / `1` |

**实现约束：** 顶栏内 `useGisRouterSync()` 在**合并** `router.query` 时，**先过滤掉**上述 `GIS_QUERY_KEYS` 中的历史键，再写入当前 `gisToQuery()` 输出，避免从 URL 中无法清除如 `did` 等问题。

**共享结果（内存）：** `gis.vitality`（经济活力结果摘要）、`gis.districts`（商圈识别摘要），供多页复用与后续接 API。

## 4. 功能需求矩阵（当前实现度）

| 模块 | 需求 | 实现说明 |
|------|------|----------|
| **顶栏** | 品牌、当前页标题、环境标签、时钟 | 已实现。 |
| **全局上下文条** | 时间、区域、数据源三件套 | `GlobalContextBar.vue`，与 `gis` 双向绑定。 |
| **分析任务条** | 显示运行中/完成/失败、保存为「已保存」 | `AnalysisTaskStrip.vue` + `pushTask` / `updateTask`。 |
| **总览** | 图层语义、信息弹窗、区域框选/点选/行政区、KPI、三种操作条、截图/报告/方案 | `OverviewView.vue` + `layerCatalog` + `exportAndBookmark.ts`（html2canvas） |
| **经济活力** | 权重归一、滑条即绘、与低空/无人机开关联动、结果分解与解释、任务与 `setVitalityResult` | `VitalityView.vue` |
| **商圈** | 点击要素/行出卡、2 选 1 对比、POI 筛选影响结果、跳转人口带 query、写 `districts` | `BusinessDistrictView.vue` |
| **人口** | 月份与全局日同步、图表/地图与月份联动、A/B 点选 | `PopulationView.vue` |
| **动态** | 时间槽位写 `timeSlotIndex`、播放、A vs B 条、曲线峰值、原因文案 | `DynamicsView.vue` |
| **三维** | 建筑点击、预设视角、深链低空 | `Scene3DView.vue` |
| **低空** | 质量%、参与模型、联动 `uavInVitalityModel` 与 `uavQualityBoost`、三链跳转 | `LowAltitudeView.vue` |

**数据现状：** 除省界 shp 与 OSM 外，各专题多为**几何演示、随机种子或开放数据样例的占位**；**正式呈现**时按 [数据与智眼说明.md](./数据与智眼说明.md) 的**最低数据清单**替换或接入服务。

**最小可演示集（与页面功能对齐）：** 底图 + 研究区 +（POI 或 活力格网/面 任一类）+ 可下载的时序小表 + 元数据表；见《数据与智眼说明》第四节。

---

## 5. 图层与数据标准（对研发）

每条专题图层在 UI 中须具备：**名称、来源（智眼/无人机/POI/多源/模型/演示）、指标说明、分级规则、单位**。  
在总览的 `LayerTreePanel` 中可展开 ℹ 查看。  

---

## 6. 非功能与约束

- **性能：** 大矢量/WMTS 需服务端切片；Cesium 建筑为演示体块。  
- **浏览器：** 现代 Chromium / Edge 优先。  
- **可访问性：** 未全面 WCAG 审计。  
- **安全：** 无鉴权，纯前端。  

---

## 7. 里程碑与缺口（对后续迭代）

| 优先级 | 项 |
|--------|-----|
| P0 | 将 `gis` 的「运行」与**自托管或合规开放数据**（WMTS/瓦片/GeoJSON 等）及可选模型服务对接，替换 `drawResult` 等中的**演示**层。 |
| P1 | 任务条支持「重试」、失败原因码；报告多图/导出 PDF。 |
| P2 | 框选真正对接后端 zonal statistics；`did` 与业务主键一致。 |
| 工程 | 可选 `vue-tsc` 在 CI 中做类型检查。 |
