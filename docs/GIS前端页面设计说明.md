# AI+GIS 城市经济空间展示平台 — 前端页面设计说明

> 依据《GIS工程初步文档》（PRD）整理；**不含登录页**；共 **7 个核心交互页面**。  
> 技术栈与 PRD 对齐：**WebGIS**，建议 **Leaflet**（二维）+ **Cesium**（三维），与后端 **PostGIS** 等通过 API 对接。

---

## 1. 设计目标与原则

### 1.1 目标

- 支撑三类角色：**城市管理部门**、**经济研究人员**、**展示与规划部门**在同一套界面中完成「浏览—分析—对比—展示」闭环。
- 体现 PRD 三条主线：**低空数据（特色）**、**武汉智眼动态感知**、**GIS 多源叠加与 AI 模型结果展示**。
- 输出形态与 PRD「系统输出成果」一致：活力分布、商圈结构、动态变化、三维与城市底图的一体化体验。

### 1.2 交互与设计原则

- **地图优先**：每个核心页均以地图或三维场景为视觉与操作中心，表格/图表为辅助。
- **时间可感知**：动态分析、智眼类数据必须配备**时间轴 / 时间选择器**，并明确「实时 vs 历史」状态。
- **分析可复现**：涉及模型（活力评估、商圈识别等）的页面需保留**参数区 + 运行/重置 + 结果图层**，便于研究与汇报。
- **分层清晰**：数据层（底图、DEM、建筑、POI、人口、无人机、智眼）通过统一**图层树**管理，避免单页堆叠失控。
- **展示友好**：大屏汇报场景下，关键 KPI 与图例字号、对比度满足远距离阅读（可作为后续主题增强项）。

## 2. 全局框架（7 页共用）

### 2.1 布局骨架

- **顶栏**：平台名称、当前页面标题、环境标识（如「演示 / 生产」）、全局时间基准（可选）、用户菜单占位（登录页外仅保留占位即可）。
- **左侧**：主导航（7 页入口）+ 可选收起。
- **主体**：各页自定义；地图类页面采用「地图全宽 + 右侧或底部抽屉面板」或「左侧图层 + 右侧分析」。
- **底栏（可选）**：坐标、比例尺、当前选中要素简要信息、数据更新时间。

### 2.2 跨页通用组件

| 组件 | 说明 |
|------|------|
| 图层树 / 图例 | 统一管理 DEM、建筑、道路、POI、人口、无人机影像/三维、智眼热力等 |
| 时间控件 | 日期、时刻、时间范围、播放/暂停（动态页强制） |
| 要素弹窗 | POI、建筑、商圈面、网格单元等属性展示 |
| 分析任务条 | 模型运行进度、失败重试、结果图层自动挂载 |
| 导出/截图 | 当前视域截图、分析报告导出入口（可与后端能力对齐） |

### 2.3 视觉与品牌（建议）

- 主色偏「城市 / 科技」深蓝或青灰，强调色用于热力高值、选中要素。
- 地图默认浅色底图利于叠加热力与智眼数据；提供暗色底图切换（研究场景）。

## 3. 七个核心交互页面说明

以下为**页面级**设计：每页对应一类高频任务，与 PRD「核心功能模块」「展示层」对应。

---

### 页面 1：城市经济空间总览（主 WebGIS 工作台）

**定位**  
平台默认落地页，**二维地图为核心**，完成多源数据快速浏览与图层组合，对应 PRD「城市经济空间 WebGIS 展示平台」的基础形态。

**主要用户任务**

- 浏览全市/片区经济相关空间底图：道路、建筑、POI、人口栅格/分区等。
- 一键开关：**经济活力分布图**（模型结果图层）、基础地理要素。
- 框选/点选查看要素属性；保存当前图层组合为「视图书签」（可选，增强研究效率）。

**界面要点**

- **中央**：Leaflet 地图（缩放、平移、测量、视域书签）。
- **右侧抽屉**：图层树、透明度、时间切片（若图层带时间维度）。
- **顶栏下方可选**：城市级 KPI 条（如全市活力指数区间、数据最新时间）。

**与 PRD 映射**  
数据层「基础空间与经济数据」+ 展示层「2D 地图展示」+ 成果「活力分布图」的快速查看入口。

---

### 页面 2：三维城市与经济空间（Cesium 场景）

**定位**  
**三维展示与空间认知**，叠加 DEM、建筑高度、无人机三维成果，将「经济指标」贴在三维空间上观察。

**主要用户任务**

- 三维漫游、倾斜/俯视切换；建筑与地形的一体化浏览。
- 切换显示：**建筑高度着色**、**某时刻活力或人口相关指标**（贴建筑或体块）。
- 叠加无人机精细模型或影像贴地（与低空模块联动时可 deep link）。

**界面要点**

- **全屏或主区**：Cesium 视图；飞行路径/视点预设（汇报用）。
- **浮动面板**：图层（地形、建筑白模/精模、无人机 mesh、经济专题）、日照/阴影可选（若后端支持）。
- **性能**：LOD、按需加载提示。

**与 PRD 映射**  
「城市三维空间建模」成果展示 +「城市三维经济展示」+ 输出成果「城市三维空间模型」。

---

### 页面 3：经济活力评估与商业分析

**定位**  
**城市经济活力评估模型（核心）** 及 **商业空间分布 / 集聚分析** 的配置与结果页。

**主要用户任务**

- 配置模型输入：**人流（智眼）**、**POI 商业密度**、**交通可达性**、**无人机观测**等权重或数据源版本。
- 运行分析 → 地图展示**活力指数**（栅格/网格/分区）；联动统计图（直方图、TOP 片区）。
- 商业分布密度、集聚程度专题切换。

**界面要点**

- **左侧**：参数表单（数据源选择、时间范围、权重滑块）、「运行分析」「重置」。
- **中央**：二维地图结果图层 + 图例分级。
- **右侧**：图表与指标解读（可折叠）；支持对比两次运行结果（可选 A/B 图层）。

**与 PRD 映射**  
模型层「城市经济活力评估模型」+ 分析层「商业空间分布分析」+ 成果「城市经济活力分布图」。

---

### 页面 4：商圈识别与结构地图

**定位**  
**商圈识别模型**（空间聚类）交互：识别商业集聚区域、编辑阈值、查看结构。

**主要用户任务**

- 设置聚类/阈值参数，执行识别；地图展示**商圈多边形/簇**。
- 点击商圈：POI 构成、人流量摘要、与模型置信度（若后端返回）。
- 导出结构图或矢量（与系统输出「商圈结构分析图」一致）。

**界面要点**

- **地图**：底图 + POI 散点 + 商圈面叠加；支持显隐 POI 类别筛选。
- **侧栏**：算法参数、聚类数量建议、运行记录列表。
- **列表视图**：商圈排名表，与地图联动高亮。

**与 PRD 映射**  
「商圈识别模型」「商业集聚分析」+ 成果「商圈结构分析图」。

---

### 页面 5：人口密度与消费潜力分析

**定位**  
**人口密度分析**与**消费潜力评估**的专题页，强调分区对比与统计。

**主要用户任务**

- 展示人口密度栅格/街道单元；刷选时间（若为多期）。
- 消费潜力评估结果分级显示；任选两个区域做对比卡片。
- 与页面 3、4 联动：从某商圈跳转到本页查看人口/潜力上下文（导航参数）。

**界面要点**

- **地图**：人口专题图层 + 可选建筑/POI 参考层。
- **侧栏**：指标说明、分级标准、筛选条件。
- **下图表区**：趋势或箱线图（若有多期数据）。

**与 PRD 映射**  
「城市人口与消费潜力分析模块」+ 数据层「人口密度数据」。

---

### 页面 6：经济动态与时序分析（重点）

**定位**  
PRD **重点模块**：**昼夜 / 周期 / 节假日**变化 + **武汉智眼**人流车流驱动下的**动态地图**。

**主要用户任务**

- 选择分析模式：昼夜对比、周内周期、节假日 vs 平日等。
- **时间轴拖拽 + 播放**：地图热力或流量图层随时间变化；支持分屏对比两个时刻。
- 查看关键事件标注（如节假日名称）对曲线的影响。

**界面要点**

- **底部或右侧显著位置**：时间轴、播放控制、速度、循环范围。
- **地图**：动态图层（人流/车流/衍生经济活跃度）；图例固定显示量级。
- **辅助图表**：24 小时曲线、日历热力（可选）。

**与 PRD 映射**  
「城市经济动态分析模块」「城市经济时空变化模型」输入侧 + 感知数据「人流密度、车流数据」+ 成果「城市经济动态变化图」。

---

### 页面 7：低空数据增强中心（特色）

**定位**  
**低空数据增强**：无人机影像/三维、精细尺度分析、与二维三维主图联动。

**主要用户任务**

- 查看无人机航线、影像覆盖范围、三维模型加载状态。
- 在地图上叠加正射/倾斜成果；框选局部做**精细尺度**查看（与全市概览区分）。
- 配置「是否参与活力/商圈模型的无人机观测项」（与页面 3 参数呼应）。

**界面要点**

- **地图**：影像切片图层、覆盖多边形、航线矢量。
- **侧栏**：数据源列表、拍摄时间、分辨率说明、开关「参与模型」。
- **快捷跳转**：打开页面 2 对应三维视点、或页面 1 同位置二维。

**与 PRD 映射**  
「低空数据增强模块」+ 数据层「无人机影像、城市三维建模、商圈精细观测」。

## 4. 页面与 PRD 模块对照表

| 页面 | PRD 核心对应 |
|------|----------------|
| 1 总览 | WebGIS 展示、多源叠加、活力图快速查看 |
| 2 三维 | 三维建模成果、三维经济展示 |
| 3 活力与商业 | 活力评估模型、商业分布与集聚 |
| 4 商圈 | 商圈识别、结构地图 |
| 5 人口与消费 | 人口密度、消费潜力 |
| 6 动态时序 | 动态分析重点、智眼数据、时空变化 |
| 7 低空增强 | 无人机与精细尺度、特色增强 |

## 5. 非本阶段范围（便于边界清晰）

- **登录、注册、权限矩阵**的完整实现（你方要求当前不含登录页；后续可接 SSO）。
- 后端 **PostGIS、GDAL 流水线、TensorFlow 模型服务** 的具体接口契约（可在你认可本设计后另立《接口与数据字典》）。

## 6. 待你确认的事项

1. **7 个页面的划分**是否与贵方业务流程一致；是否需要将「总览」与「活力」合并或拆出「报表大屏」独立页。  
2. **二维 / 三维**是强分两个路由页面（如上），还是采用「单页双引擎切换」以减少跳转。  
3. **武汉智眼**数据以实时流为主还是以历史切片为主，影响页面 6 的默认交互默认值。  
4. 是否需要**中英双语** UI（影响布局预留）。
