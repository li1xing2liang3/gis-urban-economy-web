# 商圈识别界面总结

> 路由：`/districts` · 组件：`web/src/views/BusinessDistrictView.vue`  
> 演示范围：**武汉市区**（非全省）  
> 最后更新：2026-06

---

## 一、页面定位

商圈识别页是平台的 **POI 空间聚类 + 商圈结构分析专题**，承担「参数可调、本地即时聚类、后端模型合并、双商圈对比」的职责：在地图上展示识别出的商圈多边形、过滤后的 POI 样点及影响区，并支持排名列表、详情卡片与结构图导出。

与全局框架的关系：

| 模块 | 作用 |
|------|------|
| `GlobalContextBar` | 区域模式写入 URL（本页地图不绘制区选 overlay，但结果可带 query 跳转） |
| `gisState.districts` | 商圈列表全局持久，供对比/跳转 |
| `gisState.compareDistrictIds` | 2 选 1 对比 ID 同步 |
| `LayerTreePanel` | 2 层图层可见性、透明度 |
| 分析任务条 | 「商圈识别」「同参重算」入队 |

## 四、识别参数

### 4.1 默认参数

| 参数 | 默认值 | 范围 | 作用 |
|------|--------|------|------|
| 空间聚类阈值 | 8 | 1–20 | 控制网格单元大小（越大 → 格元越大 → 簇越少） |
| 最小 POI 数 | 12 | 3–50 | 过滤稀疏网格，低于阈值不形成商圈 |
| POI 类别 | 零售/餐饮/办公 开 | 7 类可选 | 仅参与勾选类别的 POI |

阈值与最小 POI 变化时 **自动本地重算**，无需点击运行。

## 五、聚类算法（本地）

核心逻辑：`web/src/utils/poiDistrictClusters.ts` → `clusterPoisToDistricts()`

```
POI 点 → 按阈值计算 cellDeg → 网格分桶 → 过滤 minPoi
      → 计算中心/外包矩形 → 主导业态 → 置信度 → 最多 8 簇
```

| 步骤 | 说明 |
|------|------|
| 网格划分 | `cellDeg = 0.002 + (21 - threshold) × 0.00035` 度 |
| 分桶聚合 | 同格 POI 计入同一 bucket |
| 最小规模 | `bucket.pts.length >= minPoi` 才输出 |
| 商圈命名 | 样点名称前缀 + 主导业态 +「商圈」 |
| 置信度 | `0.72 + density × 0.22`，上限 0.99 |
| 排序截断 | 按 POI 数降序，取 TOP 8 |

输出 `PoiCluster`：id、name、center、ring（多边形环）、poiCount、dominantCategories、confidence。

## 六、后端模型合并

### 6.1 运行模式

| 按钮 | 行为 |
|------|------|
| 执行识别 | `gisDataService.runDistrictModel()` → 刷新 `latestModel` → 合并展示 |
| 同参重算 | 本地 420ms 模拟任务，仅 POI 聚类 |
| 重置 | 恢复默认参数与图层 |

后端失败时保留本地 POI 聚类，任务条标记 `MODEL_API_FAILED`。

### 6.2 合并策略

`mergeClustersWithModel()`：按 **地理锚点距离** 对齐，避免按序号硬套。

| 模型商圈名 | 锚点（lat, lng） |
|------------|------------------|
| 江汉路-循礼门商圈 | 30.582, 114.285 |
| 光谷-武汉东站商圈 | 30.507, 114.399 |
| 武昌滨江文旅商圈 | 30.548, 114.297 |
| 汉阳钟家村-王家湾 | 30.549, 114.254 |
| 徐东-岳家嘴商务圈 | 30.592, 114.348 |
| 街道口-广埠屯 | 30.528, 114.352 |

匹配规则：Haversine 距离 ≤ **4.5 km** 则采用模型名称/置信度；否则在锚点处生成示意矩形面。

合并结果写入 `gis.districts`（`setDistrictSummaries`）。

## 八、交互功能

### 8.1 排名列表

右栏表格列：**名称 · 置信度 · 人流**（高/中/低，由 POI 数推导）。

- 点击行或地图多边形 → 高亮 + 顶栏详情卡片
- 卡片字段：人流、活力等级、业态构成
- 选中 ID 写入 `gis.selectedDistrictId`

### 8.2 商圈 2 选 1 对比

侧栏两个下拉框选择商圈 A/B，即时显示：

| 维度 | 展示 |
|------|------|
| 人流 | 相同则「相近」，否则 `A vs B` |
| 业态 | 主导类别对比 |
| 活力 | 等级对比（核心/次核心/识别） |

对比 ID 同步至 `gis.compareDistrictIds`。

### 8.3 导出与跳转

| 功能 | 行为 |
|------|------|
| 导出结构图 | 生成 SVG（最多 6 节点圆图）→ `wuhan-district-structure.svg` |
| 带区域前往人口与消费 | `RouterLink` → `/population` 并携带 `gisToQuery()` |

## 十一、推荐使用流程

1. 启动：`cd web && npm run dev`，打开 `/districts`
2. 默认可见：**商圈识别面** + **POI 样点**（零售/餐饮/办公）
3. 拖动 **聚类阈值** 或修改 **最小 POI 数**，观察商圈数量变化
4. 勾选/取消 **业态类别**，过滤参与聚类的 POI
5. 点击 **执行识别** 合并后端/mock 模型结果
6. 在 **排名表格** 或地图上点击商圈，查看详情卡片
7. 侧栏选择 **2 个商圈对比** 人流/业态/活力
8. 需要下游分析：点击 **带区域前往人口与消费**
9. 需要汇报素材：**导出结构图** SVG

## 十二、已知限制与后续

| 项 | 说明 |
|----|------|
| 聚类算法 | **演示级网格分桶**，非 DBSCAN/OPTICS 等生产算法 |
| 商圈面形状 | 外包矩形 +  padding，非精确 Alpha Shape |
| 后端模型 | 演示环境走 fixtures；仅 3 个预设商圈带 UAV 证据 |
| 区域筛选 | 本页 **未** 按顶栏行政区过滤 POI/商圈（与总览/活力不同） |
| 最大簇数 | 本地聚类最多 8 个，超出合并到排名末尾 |
| 无人机 | `uavRouteId` 传入模型 API，本地聚类不直接使用 |
