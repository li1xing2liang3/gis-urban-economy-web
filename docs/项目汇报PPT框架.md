# 城市低空经济空间展示平台 PPT 汇报框架

> 适用于项目答辩、课程展示、阶段汇报。  
> 项目定位：以武汉市为研究范围，参考智慧城市/武汉智眼类城市感知体系，使用开放空间数据与自构造仿真数据，实现低空经济、城市经济活力、商圈识别、人口消费、经济动态、三维展示与**多机协同调度**的一体化 WebGIS **应用群**演示。

---

## 一、汇报主线

本次汇报建议围绕一条清晰主线展开：

**为什么做**：低空经济发展需要把无人机、城市空间、产业活动和人口消费联系起来分析。  
**做了什么**：建设一个面向武汉市的 AI+GIS 城市低空经济空间展示**应用群**（主 GIS 平台 + 多无人机协同调度子应用）。  
**怎么实现**：前端采用 Vue 3 + Leaflet + Cesium，数据层使用武汉空间数据、DEM、POI、道路、建筑、单机/编队仿真数据。  
**展示什么能力**：空间总览、三维城市、经济活力、商圈识别、人口消费、经济动态、低空单机航线仿真、**多机协同调度回放**。  
**下一步怎么完善**：接入真实后端服务、真实三维城市数据、无人机监管、**运行时编队调度引擎**与低空航路服务。

### 第 2 页：项目背景

**标题**：低空经济与城市空间治理需求

- 武汉作为超大城市，商业中心、交通枢纽、高校园区、产业片区空间关系复杂，适合做低空经济空间分析示范。

## 四、建议讲稿结构

### 1. 开场

大家好，我们小组展示的项目是“城市低空经济空间展示平台”**应用群**。项目以武汉市为研究范围，希望通过 AI+GIS 技术，把城市经济空间分析、单机无人机应用与**多机协同调度**结合起来。

### 2. 背景

低空经济正在成为城市发展的新方向，但无人机航线、城市建筑、商业活动、人流消费之间存在复杂的空间关系。因此，我们希望搭建一个平台，把这些要素放在同一张地图和三维场景中进行展示和分析。

### 3. 系统介绍

平台采用 Vue 3、Leaflet 和 Cesium 实现。二维地图用于空间总览和专题分析，三维场景用于展示建筑空间和无人机航线，数据层使用武汉范围空间数据和仿真经济数据完成演示闭环。

### 4. 功能展示

我们重点展示**主平台七个功能**与**编队调度子应用**：空间总览、三维城市、经济活力、商圈识别、人口消费、经济动态、低空单机路径仿真，以及多机协同调度工作台。每个模块都围绕武汉城市经济空间展开，并与低空经济场景形成联系。

### 5. 总结

本项目当前实现了从数据展示、模型分析到低空飞行仿真与**编队协同回放**的完整前端流程。后续如果接入真实后端数据、真实 3D Tiles、无人机任务服务与**运行时调度引擎**，可以进一步扩展为城市低空经济规划和展示系统。

- 所有数据说明建议统一写为“开放数据与仿真数据支撑演示”，不要表述为已接入武汉智眼真实生产数据。
- 汇报重点放在“系统完成度”和“功能闭环”，不要只讲页面美观。
- 低空无人机部分建议作为展示高潮，放在后半段演示。
- 现场演示前建议提前打开本地服务，并按演示顺序逐页检查，避免加载等待影响节奏。
