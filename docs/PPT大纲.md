## 汇报主线（15 秒开场）

> **不是「做一张武汉地图」，而是把低空无人机观测、城市经济活力、商圈与人口消费，放进同一套可交互、可扩展的 AI+GIS 工程系统里完成闭环。**

### 第 4 页 · 工程架构 ★ 重点页

**标题**：平台总体技术架构

**建议图示（四层）**

```
展示层  Vue 3 + Leaflet + Cesium + 图表/任务条
分析层  活力模型 / 商圈聚类 / 时序动态 / 航线优化
```

- `gisState` + `useGisRouterSync`：13+ URL 参数跨页同步
- 数据脚本：`generate:mock-wuhan`、`prepare:wuhan-geospatial` 等

**创新亮点**
- 低空模块写入全局分析状态，不是孤立展示页

## D. 联动与收尾（第 19–23 页）

### 第 19 页 · 模块联动闭环 ★ 创新总结

**标题**：从空间底图到低空仿真的分析闭环

**建议图示**

```
空间总览（底图）
   ↓
经济活力 ←—— 低空观测因子（质量/覆盖）
   ↓           ↓
商圈识别 ←—— 热区复核航线
   ↓
人口消费（需求侧）
   ↓
经济动态（时间侧）
   ↓
单机低空（/lowaltitude）
   ↓
编队协同（/fleet-dispatch）→ 任务队列 / 活力回写
   ↕
三维城市（立体表达）
```

**三句话收束**
1. **空间**：总览定范围  
2. **分析**：活力 → 商圈 → 人口 → 动态层层递进  
3. **低空**：单机观测补采 + **多机协同调度**，反哺分析模型  

**工程**：全局 `gisState` + URL 参数贯穿全链路

**标题**：从前端演示到真实服务接入

- 编队：`/wuhan/uav/fleet-dispatch-plans`、`fleet-telemetry`、`fleet-conflicts`

> 本项目面向武汉低空经济场景，构建了 AI+GIS **应用群**：主平台 + **多无人机协同调度子应用**。  
> **创新上**，我们把无人机观测、经济活力、商圈人口、时序动态与**编队协同运行**打通，形成低空经济空间分析闭环。  
> **工程上**，平台具备全局状态管理、API/Mock 双通道、模块化模型与任务工作流，已具备向真实后端与三维实景平滑扩展的能力。

**当前不足**
- 部分经济、人流、低空数据仍为仿真  
- 三维以演示白模为主，待接入真实 3D Tiles  
- 无 Cesium 第一人称跟随、无 DEM 净空剖面 panel（后续扩展）

**后续方向**
- PostGIS 空间查询 + 模型服务化  
- 合规三维城市数据 + DEM + 禁飞区  
- 低空航路规划、任务调度、遥测回放

## 答辩金句（可直接背）

**创新**
- 「我们把无人机从展示图层，升级为经济活力模型的第 5 类观测因子。」
- 「航线不是随便画线，而是对应夜间消费、枢纽物流等低空经济任务。」
- 「平台实现从空间总览 → 模型分析 → 时序演化 → 单机/多机低空仿真的完整叙事。」

**工程**
- 「所有页面共享 gisState，筛选条件通过 URL 同步，可复现、可分享。」
- 「gisDataService 保证 API 不可用时不影响答辩，这是工程上的容错设计。」
- 「活力模型、商圈聚类独立成工具模块，后续可直接替换为后端算法服务。」

## PPT 制作规范

- 每页 **3–4 个要点**，优先「截图 + 关键词 + 口述」
- 每页右下角标注 **▎创新** / **▎工程** 各一句
- 数据表述统一：**开放数据与仿真数据支撑演示**
- 低空模块放在后半段，作为演示高潮
- 现场演示前启动 **5173** 前端，按第 21 页顺序预检；素材见 `presentation-assets/`
